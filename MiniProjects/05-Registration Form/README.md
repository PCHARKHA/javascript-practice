# 📝 Form Validation

A simple and interactive **form validation project** built using **HTML**, **CSS**, and **Vanilla JavaScript**.

The project validates user input on form submission and provides clear error messages for invalid fields.

![Form Validation](assets/FormValidation.png)

## 🚀 Features

- 🧑 Full name validation
- 📧 Email validation using Regular Expressions
- 📱 Phone number validation
- 🔢 Age validation
- ⚧️ Gender selection validation
- 🔐 Password strength validation
- 🔁 Confirm password matching
- ☑️ Terms & Conditions validation
- ✅ Success message after valid submission
- 📱 Responsive and clean UI

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Regular Expressions (Regex)

---

## ⚙️ How It Works

1. User enters their details in the registration form.
2. JavaScript listens for the form submission.
3. Each field is validated individually.
4. Invalid fields display appropriate error messages.
5. The form submission is prevented if any validation fails.
6. A success message is displayed when all fields are valid.
