# 📝 Writing Analyzer

A simple and interactive **Writing Analyzer** built using **HTML**, **CSS**, and **Vanilla JavaScript**.

The application analyzes the user's text in real time and provides detailed writing statistics such as word count, reading time, vocabulary richness, sentence analysis, and much more.

## 🚀 Features

* ✍️ Real-time text analysis
* 🔢 Character, word, sentence, and paragraph counting
* ⏱️ Reading time and speaking time estimation
* 📏 Average words per sentence calculation
* 📝 Longest word and longest sentence detection
* 📚 Vocabulary richness analysis
* 📈 Most frequently used words
* 🚫 Filler word detection
* 🗑️ One-click clear editor functionality
* 📱 Responsive and clean user interface

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)

## ⚙️ How It Works

1. The user enters or pastes text into the editor.
2. The application listens for every input event.
3. JavaScript analyzes the text in real time.
4. Basic statistics such as characters, words, sentences, and paragraphs are calculated.
5. Advanced statistics including reading time, speaking time, vocabulary richness, longest sentence, longest word, most frequent words, and filler words are generated.
6. The statistics update instantly as the user continues typing.
7. The user can clear the editor and begin a new analysis.
